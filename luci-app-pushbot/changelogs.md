# 更新日志

- **2026-09-27**（v6.01）：在线更新修复与配置管理
  - 修复+优化：**在线更新**——修复 IPK 更新失败、更新后界面丢失翻译与偶发卡死；等待 30 秒 → 10 秒装好即刷新；新增清除下载；安装一次后不再提示"允许未信任"
  - 新增：**配置管理**——一键恢复出厂设置，或仅重置系统项、保留当前推送渠道的 Token/UID/主题
  - 修复+优化：**总开关**——关闭后不再残留推送；「已启用」点击即保存并启停服务，无需再点保存
  - 修复：**渠道校验**——仅用 WxPusher/ntfy/Gotify 不再误报缺 Token；预览不再误报未改动项；测试按钮检测到改动会先提示保存再测
  - 优化：**界面**——卡片立体投影（亮/暗黑）、页面下移留白、移动端保存按钮换行；「时间间隔内流量限制」改名**「流量报警阈值」**
  - 新增：**OpenWrt 25.12 源手动编译**——Actions 手动触发，产物发布于 `OpenWRT25.12-*` Release


- **2026-09-22**（v6.00）：在线更新 + 事件推送修复
  - 新增：**在线更新**——检查到新版本后可一键更新（自动下载安装）或手动拉取（下载带进度环，完成后点击安装）；安装后 30 秒自动刷新页面；也支持浏览器直接下载安装包
  - 修复：**设备上下线、登录提醒等事件推送从未成功**——因历史遗留问题导致所有事件通知静默失败，现已修复
  - 优化：**WxPusher TopicID** 对齐官方限制（单条消息最多 5 个，超出自动忽略）；分隔符兼容中英文逗号与空格
- **2026-09-20**（v5.18）：新增 WxPusher 渠道与内容卡片化，主版本 5.17 → 5.18
  - 新增：**WxPusher 渠道**——填 App Token 即可推送，用户 UID 与主题 TopicID 均支持多个，两者至少启用其一（官方单条消息最多 5 个主题，超出部分自动忽略）；内容自动转 HTML，微信内直接可读
  - 新增：**推送内容分模块卡片化**——表格改用无边框 HTML 表格，不再受 Markdown 表格在部分渠道不渲染的影响，各模块独立成卡片
  - 新增：**设备别名批量录入**——多个 `MAC-别名` 用逗号或空格一次粘贴，自动拆分为独立条目
  - 优化：**手机端渠道按钮**——每行排满 5 个，按钮、图标与文字随卡片宽度等比缩放，文字不再被省略或挤压
  - 优化：**流量源健康检查**——检测到 nlbw 即优先使用，异常时自动重启一次，仍不可用则回退 wrtbw
  - 优化：**白名单设备保持显示**，仅不再发送上下线通知
  - 优化：**补全界面说明文案的汉化**
  - 测试平台：x86_64（官方 APK）、MT798x（IPK）
- **2026-09-19**（v5.17-r4 → r24）：黑名单与流量源优化
  - 新增：**nlbw 启动健康检查**——系统重启后自动检测并修复 nlbw 服务异常
  - 新增：**WiFi 认证失败监控**（MTK 闭源驱动）——提取失败 MAC 地址并分组统计
  - 优化：**黑名单同步机制**——解决文件与内核 set 不一致问题
  - 优化：**流量源探测**——检测到 nlbw 即默认使用，启动时自动检查可用性
  - 优化：**在线设备列表**——白名单设备正常显示，显示流量来源
  - 修复：**白名单设备不显示**、**黑名单超时解封失效**、**精简模式预览异常**
- **2026-08-28**（v5.17）：安全监控优化，主版本 5.16 → 5.17

- **2026-08-26**（v5.16）：WiFi 监控全面升级，主版本 5.15 → 5.16
  - 新增：**WiFi 连接/离线提醒**——设备连接 WiFi 或持续离线超过 2 分钟时推送通知；支持漫游、短暂信号波动不误报
  - 新增：**WiFi 认证失败提醒**——错误密码连接尝试达到阈值时推送通知，显示失败次数和 MAC（MTK 闭源驱动仅显示失败次数）
  - 新增：**在线设备列表显示流量来源**——可查看当前使用的是 nlbwmon 还是 wrtbwmon
  - 优化：**默认流量源改为 nlbwmon**——自动检测可用流量源，优先使用 nlbwmon（性能更好、数据更准确）
  - 优化：**MAC 过滤重构**——从单选改为多选开关模式，忽略/仅通知列表互斥，接口独立
  - 优化：**异常流量检测**——设备在线不足 2 个检测周期不触发告警（避免上线首屏误报）
  - 测试平台：开源 mac80211 驱动（x86）、MTK 闭源驱动（MT798x）
- **2026-08-18**（v5.14）：主版本 5.13 → 5.14

  - 优化：**URL 获取全面增强**——自动轮换可用 API、失败明确提示"获取失败"、可指定出口接口适配多 WAN、预置列表实测筛选扩充（v4 / v6 各 9 个）、一键"恢复默认"

- **2026-08-13**（v5.13）：拉黑功能增强（白名单 / IPv6 / 即时应用），主版本 5.12 → 5.13
  - 新增：**白名单**——支持单个 IP 与标准 IP 段（CIDR），如 `192.168.1.5` / `10.1.1.0/24` / `2001:db8::1` / `fd00::/32`，多个用空格分隔；白名单内的 IP 即使登录失败也不会被拉黑
  - 新增：**IPv6 拉黑**——黑名单支持 IPv6 地址与网段（此前仅 IPv4）
  - 优化：**拉黑即时生效**——新增 / 修改 / 删除 / 清空黑名单保存后立即应用到防火墙，无需等待轮询或重启
  - 修复：清空黑名单后规则彻底移除（此前可能残留规则，需手动重启防火墙才解除）
