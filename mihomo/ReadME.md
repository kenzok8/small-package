# 核心替换 / Core Replacement

> 此 mihomo 核心并不是唯一的. 您也可以使用 Nikki 或其他包的 mihomo 核心.\
> 只要它们的 `PROVIDES` 字段为 **mihomo**, 且 `/usr/bin/mihomo` 有可用于执行的二进制文件或链接

> This mihomo core is not the only option. you can also use the mihomo core from Nikki or other packages.\
> provided that their `PROVIDES` field is set to **mihomo** and there is an executable binary or link at `/usr/bin/mihomo`.
